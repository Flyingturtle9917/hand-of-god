# 천리안 '신의손' 레트로 온라인 타자게임

90년대 PC통신(천리안/하이텔) 시절 유행했던 전설의 온라인 타자 대결 게임 **'신의손'**을 **새롬데이타맨프로** 터미널 에뮬레이션 환경으로 구현한 프로젝트입니다.

---

## 🌟 주요 기능
- **새롬데이타맨프로 98 레트로 UI & 사운드**: 도스 윈도우 창틀, 네이비 블루 터미널, CRT 모니터 효과, 모뎀 핸드셰이크음, BEEP음
- **10인 멀티플레이 대결**: 방 개설(`/방만들기`), 방 입장(`/입장`), 한 방당 최대 10인 실시간 타자 배틀
- **'신의손' 타자 엔진**: `/문제` 5초 카운트다운 후 출제, 13초 제한 시간
- **정밀 정확도 & 오타 핸디캡**: 음소(자모) 분해 기반 레벤슈타인 편집 거리 계산, 오타 핸디캡 적용 Net CPM 순위 정렬
- **레벨 & 칭호 시스템**: 흙손(Lv.1)부터 신의손(Lv.10)까지 누적 경험치(EXP) 자동 승급
- **가상 경쟁자(봇) 소환**: 1인 플레이 시에도 `/봇추가 3` 명령어로 실시간 순위 대결 가능

---

## 🚀 배포 및 실행
- `npm install`
- `npm start` (포트: 3000)
